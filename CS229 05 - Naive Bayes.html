5.1 Generative vs. Discriminative Learning

All of the algorithms we have studied so far — linear regression, logistic regression, and the generalized linear models — share a common character. Given a training set, they search directly for a function mapping from inputs $\boldsymbol{x}$ to labels $y$. Such methods are called discriminative learning algorithms because they learn to discriminate between classes: they model $p(y \mid \boldsymbol{x})$ directly, or they learn a mapping $h : \mathcal{X} \to \mathcal{Y}$ outright. Logistic regression, for instance, parameterizes $p(y \mid \boldsymbol{x})$ as a sigmoid function and fits the parameters by maximizing the conditional log-likelihood.

A second, philosophically distinct family of algorithms takes a different approach. Rather than asking "given these features, how do I predict the label?", a generative learning algorithm asks two separate questions: "What do the features look like for examples of class 0?" and "What do the features look like for examples of class 1?" It builds an explicit probabilistic model of each class separately, and then at prediction time compares how well a new example fits each class model. This is closer to how a radiologist might be trained: they study many malignant tumors until they develop a mental model of what malignancy looks like, then study many benign tumors the same way, and finally classify a new patient by asking which of the two mental models the new case most resembles.

In this chapter we formalize this distinction, develop Gaussian Discriminant Analysis (GDA) for continuous features, and then build the Naïve Bayes classifier for discrete and text features. Along the way we will see that the choice between generative and discriminative approaches involves a fundamental trade-off between the strength of modeling assumptions and robustness to misspecification.

5.1.1 Discriminative Algorithms and $p(y \mid \boldsymbol{x})$

Definition · Discriminative Learning Algorithm

A discriminative learning algorithm is one that models the conditional distribution $p(y \mid \boldsymbol{x};\, \theta)$ directly, or equivalently learns a decision function $h_\theta : \mathcal{X} \to \mathcal{Y}$, by maximizing the conditional log-likelihood: $$\ell_{\text{disc}}(\theta) = \sum_{i=1}^{m} \log p(y^{(i)} \mid \boldsymbol{x}^{(i)};\, \theta).$$ No model of the marginal distribution $p(\boldsymbol{x})$ is required or estimated.

Logistic regression is the canonical discriminative algorithm for binary classification. It sets $p(y=1 \mid \boldsymbol{x};\, \boldsymbol{\theta}) = \sigma(\boldsymbol{\theta}^\top \boldsymbol{x})$ where $\sigma(z) = 1/(1+e^{-z})$ and maximizes the resulting likelihood. The algorithm searches for a decision boundary — a hyperplane $\boldsymbol{\theta}^\top \boldsymbol{x} = 0$ — that separates positive from negative examples in input space.

5.1.2 Generative Algorithms and $p(\boldsymbol{x} \mid y)$

Definition · Generative Learning Algorithm

A generative learning algorithm models the class-conditional density $p(\boldsymbol{x} \mid y;\, \theta)$ and the class prior $p(y;\, \phi)$. Parameters are estimated by maximizing the joint log-likelihood: $$\ell_{\text{gen}}(\theta, \phi) = \sum_{i=1}^{m} \log p(\boldsymbol{x}^{(i)}, y^{(i)};\, \theta, \phi) = \sum_{i=1}^{m} \bigl[\log p(\boldsymbol{x}^{(i)} \mid y^{(i)};\, \theta) + \log p(y^{(i)};\, \phi)\bigr].$$ At prediction time, Bayes' rule is used to compute $p(y \mid \boldsymbol{x})$ from the learned components.

5.1.3 Bayes' Rule for Prediction

Once a generative model has been fit, predictions are made by computing the posterior class probability via Bayes' rule:

Prediction Rule
$$p(y \mid \boldsymbol{x}) = \frac{p(\boldsymbol{x} \mid y)\, p(y)}{p(\boldsymbol{x})} = \frac{p(\boldsymbol{x} \mid y)\, p(y)}{\sum_{y'} p(\boldsymbol{x} \mid y')\, p(y')}$$

For the binary classification case, the predicted label is the maximizer:

$$\hat{y} = \operatorname*{arg\,max}_{y \in \{0,1\}} p(y \mid \boldsymbol{x}) = \operatorname*{arg\,max}_{y \in \{0,1\}} p(\boldsymbol{x} \mid y)\, p(y).$$

Notice that the denominator $p(\boldsymbol{x})$ is constant with respect to $y$ and can be dropped when all we need is the most probable class. If we need calibrated probabilities (not just the argmax), we must compute the full normalization.

Intuition · Why Model the Joint Instead of the Conditional?

A discriminative algorithm answers the question: "Given these features, what is the label?" A generative algorithm answers the prior question: "How are features generated in each class?" The generative approach is more informative — it builds a complete probabilistic world-model — but it also makes stronger assumptions. When those assumptions are correct (even approximately), the extra structure provides a tighter statistical fit. When they are wrong, the model can be badly miscalibrated. This trade-off recurs throughout machine learning.

5.2 Gaussian Discriminant Analysis

Our first generative learning algorithm is designed for the case where the features $\boldsymbol{x} \in \mathbb{R}^n$ are continuous-valued. Gaussian Discriminant Analysis (GDA) assumes that the class-conditional distributions are multivariate Gaussian. This is a strong but often approximately correct assumption for many real-valued feature vectors in practice, such as measurements of physical objects or biological quantities.

5.2.1 The Multivariate Gaussian Distribution

The building block of GDA is the multivariate Gaussian (normal) distribution, which generalizes the familiar one-dimensional bell curve to vector-valued random variables.

Definition · Multivariate Gaussian Distribution

A random vector $\boldsymbol{z} \in \mathbb{R}^n$ follows a multivariate Gaussian distribution with mean $\boldsymbol{\mu} \in \mathbb{R}^n$ and covariance matrix $\Sigma \in \mathbb{R}^{n \times n}$ (where $\Sigma \succ 0$) if its probability density function is: $$p(\boldsymbol{z};\, \boldsymbol{\mu}, \Sigma) = \frac{1}{(2\pi)^{n/2} \lvert\Sigma\rvert^{1/2}} \exp\!\left(-\tfrac{1}{2}(\boldsymbol{z} - \boldsymbol{\mu})^\top \Sigma^{-1} (\boldsymbol{z} - \boldsymbol{\mu})\right).$$ We write $\boldsymbol{z} \sim \mathcal{N}(\boldsymbol{\mu}, \Sigma)$, with $\mathbb{E}[\boldsymbol{z}] = \boldsymbol{\mu}$ and $\text{Cov}(\boldsymbol{z}) = \mathbb{E}[(\boldsymbol{z}-\boldsymbol{\mu})(\boldsymbol{z}-\boldsymbol{\mu})^\top] = \Sigma$.

The shape of the Gaussian density is controlled entirely by $\boldsymbol{\mu}$ and $\Sigma$. The mean $\boldsymbol{\mu}$ shifts the center; the covariance $\Sigma$ controls the spread and orientation of the elliptical contours. When $\Sigma = \sigma^2 I$, the contours are circles and all dimensions are uncorrelated. Off-diagonal entries in $\Sigma$ introduce correlations, stretching the ellipse along directions determined by the eigenvectors of $\Sigma$.

5.2.2 The GDA Model

Definition · Gaussian Discriminant Analysis Model

For binary classification with $y \in \{0, 1\}$ and $\boldsymbol{x} \in \mathbb{R}^n$, the GDA model specifies: $$y \sim \text{Bernoulli}(\phi), \qquad \boldsymbol{x} \mid y=0 \sim \mathcal{N}(\boldsymbol{\mu}_0, \Sigma), \qquad \boldsymbol{x} \mid y=1 \sim \mathcal{N}(\boldsymbol{\mu}_1, \Sigma).$$ The parameters are $\phi \in [0,1]$, $\boldsymbol{\mu}_0, \boldsymbol{\mu}_1 \in \mathbb{R}^n$, and $\Sigma \in \mathbb{R}^{n \times n}$ (positive semi-definite). Note that both classes share the same covariance matrix $\Sigma$.

The shared covariance constraint is the standard GDA formulation. Using a single $\Sigma$ for both classes constrains the model to a linear decision boundary, as we will see below. If one instead uses class-specific covariances $\Sigma_0$ and $\Sigma_1$, the resulting algorithm is called Quadratic Discriminant Analysis (QDA), and produces a quadratic (non-linear) decision boundary at the cost of estimating twice as many parameters.

5.2.3 MLE Parameter Estimation

Given a training set $\{(\boldsymbol{x}^{(i)}, y^{(i)})\}_{i=1}^{m}$, we fit GDA by maximizing the joint log-likelihood $\ell(\phi, \boldsymbol{\mu}_0, \boldsymbol{\mu}_1, \Sigma) = \sum_{i=1}^{m} \log p(\boldsymbol{x}^{(i)} \mid y^{(i)}) + \log p(y^{(i)})$. Taking derivatives and setting them to zero yields closed-form estimates with elegant interpretations.

Theorem · GDA Maximum Likelihood Estimates

The maximum likelihood estimates of the GDA parameters are: $$\hat{\phi} = \frac{1}{m}\sum_{i=1}^{m} \mathbf{1}\{y^{(i)} = 1\}$$ $$\hat{\boldsymbol{\mu}}_k = \frac{\sum_{i=1}^{m} \mathbf{1}\{y^{(i)} = k\}\, \boldsymbol{x}^{(i)}}{\sum_{i=1}^{m} \mathbf{1}\{y^{(i)} = k\}}, \quad k \in \{0, 1\}$$ $$\hat{\Sigma} = \frac{1}{m} \sum_{i=1}^{m} \bigl(\boldsymbol{x}^{(i)} - \hat{\boldsymbol{\mu}}_{y^{(i)}}\bigr)\bigl(\boldsymbol{x}^{(i)} - \hat{\boldsymbol{\mu}}_{y^{(i)}}\bigr)^\top$$

Proof Sketch

We maximize $\ell = \sum_i \bigl[-\frac{n}{2}\log(2\pi) - \frac{1}{2}\log|\Sigma| - \frac{1}{2}(\boldsymbol{x}^{(i)} - \boldsymbol{\mu}_{y^{(i)}})^\top\Sigma^{-1}(\boldsymbol{x}^{(i)} - \boldsymbol{\mu}_{y^{(i)}}) + y^{(i)}\log\phi + (1-y^{(i)})\log(1-\phi)\bigr]$. Setting $\partial\ell/\partial\phi = 0$ immediately gives $\hat\phi$. Setting $\partial\ell/\partial\boldsymbol{\mu}_k = 0$ and using the fact that only examples with $y^{(i)} = k$ contribute to the $\boldsymbol{\mu}_k$ gradient gives $\hat{\boldsymbol{\mu}}_k$ as the class-conditional sample mean. The covariance estimate follows from $\partial\ell/\partial\Sigma^{-1} = 0$ using the matrix derivative identity $\partial\log|\Sigma|/\partial\Sigma = \Sigma^{-\top}$. □

Example · Fitting GDA to Tumor Data

Setup. Suppose we have $m=100$ patients with two features $\boldsymbol{x} = (x_1, x_2)^\top$ representing tumor size and cell adhesion. Of the 100 patients, 30 have malignant tumors ($y=1$) and 70 have benign ($y=0$). From the data: the malignant group has sample mean $\bar{\boldsymbol{x}}_1 = (3.2, 1.8)^\top$ and the benign group has $\bar{\boldsymbol{x}}_0 = (0.8, 0.5)^\top$. The pooled sample covariance (weighted 30/100 and 70/100) is $\hat\Sigma = \bigl(\begin{smallmatrix}1.2 & 0.3\\0.3 & 0.8\end{smallmatrix}\bigr)$.

Estimates. By the theorem above: $\hat\phi = 30/100 = 0.3$, $\hat{\boldsymbol{\mu}}_1 = (3.2, 1.8)^\top$, $\hat{\boldsymbol{\mu}}_0 = (0.8, 0.5)^\top$, and $\hat\Sigma$ as given. A new patient with $\boldsymbol{x}^* = (2.0, 1.2)^\top$ is classified by computing the posterior $p(y \mid \boldsymbol{x}^*)$ via Bayes' rule using these estimates.

Interpretation. The means $\hat{\boldsymbol{\mu}}_k$ are exactly the class-specific sample averages of the feature vectors — the most natural possible estimators. The shared covariance $\hat\Sigma$ is a weighted average of the within-class scatter matrices, ensuring that both Gaussians have the same shape (though different centers).

5.2.4 Relationship to Logistic Regression

There is a remarkable structural relationship between GDA and logistic regression. If we compute the GDA posterior $p(y=1 \mid \boldsymbol{x})$ as a function of $\boldsymbol{x}$ using Bayes' rule, we find:

$$p(y=1 \mid \boldsymbol{x}) = \frac{1}{1 + \exp(-\boldsymbol{\theta}^\top \boldsymbol{x})}$$ for some parameters $\boldsymbol{\theta}$ determined by $\boldsymbol{\mu}_0, \boldsymbol{\mu}_1, \Sigma, \phi$. In other words, the GDA posterior is exactly a logistic function of $\boldsymbol{x}$, which is the form assumed by logistic regression.
Theorem · GDA Implies Logistic Posterior

If $p(\boldsymbol{x} \mid y=k) = \mathcal{N}(\boldsymbol{\mu}_k, \Sigma)$ and $p(y=1) = \phi$, then the posterior satisfies: $$p(y=1 \mid \boldsymbol{x}) = \sigma(\boldsymbol{\theta}^\top \boldsymbol{x} + \theta_0)$$ where $\sigma(z) = 1/(1+e^{-z})$, and $$\boldsymbol{\theta} = \Sigma^{-1}(\boldsymbol{\mu}_1 - \boldsymbol{\mu}_0), \qquad \theta_0 = -\tfrac{1}{2}\boldsymbol{\mu}_1^\top\Sigma^{-1}\boldsymbol{\mu}_1 + \tfrac{1}{2}\boldsymbol{\mu}_0^\top\Sigma^{-1}\boldsymbol{\mu}_0 + \log\frac{\phi}{1-\phi}.$$

Proof

By Bayes' rule, $p(y=1 \mid \boldsymbol{x}) = \sigma(\log[p(\boldsymbol{x}\mid y=1)p(y=1)] - \log[p(\boldsymbol{x}\mid y=0)p(y=0)])$. The log-ratio of the Gaussian densities is: $$\log\frac{p(\boldsymbol{x}\mid y=1)}{p(\boldsymbol{x}\mid y=0)} = -\tfrac{1}{2}(\boldsymbol{x}-\boldsymbol{\mu}_1)^\top\Sigma^{-1}(\boldsymbol{x}-\boldsymbol{\mu}_1) + \tfrac{1}{2}(\boldsymbol{x}-\boldsymbol{\mu}_0)^\top\Sigma^{-1}(\boldsymbol{x}-\boldsymbol{\mu}_0).$$ Expanding and collecting terms linear in $\boldsymbol{x}$ gives $\boldsymbol{\theta} = \Sigma^{-1}(\boldsymbol{\mu}_1 - \boldsymbol{\mu}_0)$, with the quadratic terms $\boldsymbol{x}^\top\Sigma^{-1}\boldsymbol{x}$ canceling due to the shared $\Sigma$. Adding $\log(\phi/(1-\phi))$ completes the expression. □

💡
Key Insight: The theorem says GDA $\Rightarrow$ logistic form for the posterior, but the converse is false. Logistic regression does not assume Gaussians; its assumptions are strictly weaker. This means GDA's assumptions are a special case — stronger, and potentially wrong.

Data Science Application · GDA for Medical Diagnosis

GDA is widely used in medical imaging and biomarker classification. When feature vectors represent continuous measurements (cell size, enzyme levels, pixel intensities in MRI), fitting Gaussian densities is computationally simple: it reduces to computing class-specific means and a pooled covariance matrix — no iterative optimization required. On small clinical datasets (as few as 50 examples per class), GDA's stronger assumptions often give better generalization than logistic regression, which would require more data to estimate the decision boundary reliably from scratch.

5.3 Naïve Bayes for Text Classification

GDA handles continuous features beautifully, but what do we do when features are discrete — specifically, when the input is raw text? This is our first major encounter with natural language processing (NLP). The canonical application is email spam classification: given a piece of email, predict $y=1$ (spam) or $y=0$ (not spam). The same formulation applies to product categorization, sentiment analysis, and document routing.

The central challenge is representation. A piece of email is a variable-length string of words drawn from a large vocabulary. We need to convert it to a fixed-length vector $\boldsymbol{x}$ before we can apply any learning algorithm. The Naïve Bayes algorithm makes this conversion explicit and principled.

5.3.1 Bag-of-Words Feature Representation

Fix a vocabulary (dictionary) of $n$ words. In practice, rather than using the entire Oxford English Dictionary, we use the top $n$ most frequent words appearing in the training corpus — a common choice is $n = 10{,}000$. Words not in the top $n$ are either discarded or mapped to a special UNK (unknown) token.

Definition · Binary Bag-of-Words Feature Vector

Given a vocabulary $\mathcal{V} = \{w_1, w_2, \ldots, w_n\}$ and an email $e$, the binary bag-of-words feature vector is $\boldsymbol{x} \in \{0,1\}^n$ where: $$x_j = \mathbf{1}\{w_j \text{ appears in } e\}, \quad j = 1, \ldots, n.$$ Each $x_j$ indicates the presence (1) or absence (0) of word $w_j$ in the email, regardless of how many times it appears.

With a vocabulary of $n = 10{,}000$ words, the feature vector $\boldsymbol{x} \in \{0,1\}^{10000}$ is extremely high-dimensional. An email containing the words "buy", "discount", and "mortgage" would have $x_j = 1$ for those three dictionary positions and $x_j = 0$ everywhere else.

5.3.2 The Naïve Bayes Assumption

Now we want to build a generative model. As in GDA, we model $p(\boldsymbol{x} \mid y)$ and $p(y)$. But here $\boldsymbol{x} \in \{0,1\}^n$ with $n = 10{,}000$. A fully general model of $p(\boldsymbol{x} \mid y)$ as a discrete distribution over all $2^{10000}$ possible values of $\boldsymbol{x}$ would require $2^{10000} - 1$ parameters — an astronomical number. We need a simplifying assumption.

By the chain rule of probability, we can always write: $$p(x_1, \ldots, x_n \mid y) = p(x_1 \mid y)\, p(x_2 \mid x_1, y)\, p(x_3 \mid x_1, x_2, y) \cdots p(x_n \mid x_1, \ldots, x_{n-1}, y).$$ This is an exact decomposition requiring no assumptions. The Naïve Bayes algorithm approximates each factor by dropping the conditioning on all other $x_j$'s:

Definition · Naïve Bayes Assumption

The Naïve Bayes conditional independence assumption states that the features $x_1, \ldots, x_n$ are conditionally independent given $y$: $$p(x_1, x_2, \ldots, x_n \mid y) = \prod_{j=1}^{n} p(x_j \mid y).$$ Equivalently, $x_j \perp\!\!\!\perp x_k \mid y$ for all $j \neq k$: knowing the class label $y$ renders each word's presence independent of every other word's presence.

Figure 5.2. Probabilistic graphical model for Naïve Bayes. The class label $Y$ (navy) is the single parent of all feature nodes $X_1, \ldots, X_n$ (blue/green). The absence of edges between $X_j$ nodes encodes the conditional independence assumption: once $Y$ is observed, all features are independent of one another. Gold arrows indicate the generative direction — $Y$ causes (or conditions) each feature.
Warning · The Naïve Bayes Assumption is Almost Always False

In real email text, knowing that the word "buy" appears makes it more likely that "now", "discount", and "click" also appear — words are far from conditionally independent. The name "Naïve" is apt. Despite this, Naïve Bayes classifiers often work surprisingly well in practice. The key insight is that even a misspecified model can produce accurate MAP predictions as long as the ordering of class posteriors is preserved, which the Naïve Bayes assumption tends to maintain for classification tasks even when it fails for density estimation.

5.3.3 Parameter Estimation via MLE

Under the Naïve Bayes assumption, the model parameters are: the class prior $\phi_y = p(y=1)$, and for each word $j$, the word probabilities $\phi_{j|y=1} = p(x_j=1 \mid y=1)$ and $\phi_{j|y=0} = p(x_j=1 \mid y=0)$. The total parameter count is $1 + 2n$ — linear in the vocabulary size, not exponential.

MLE Estimates
$$\hat{\phi}_y = \frac{\sum_{i=1}^{m}\mathbf{1}\{y^{(i)}=1\}}{m}, \quad \hat{\phi}_{j|y=1} = \frac{\sum_{i=1}^{m}\mathbf{1}\{x_j^{(i)}=1,\, y^{(i)}=1\}}{\sum_{i=1}^{m}\mathbf{1}\{y^{(i)}=1\}}, \quad \hat{\phi}_{j|y=0} = \frac{\sum_{i=1}^{m}\mathbf{1}\{x_j^{(i)}=1,\, y^{(i)}=0\}}{\sum_{i=1}^{m}\mathbf{1}\{y^{(i)}=0\}}$$

These estimators have clean interpretations: $\hat\phi_{j|y=1}$ is the fraction of spam emails that contain word $j$, and $\hat\phi_{j|y=0}$ is the fraction of non-spam emails that contain word $j$. Parameter fitting is pure counting — no gradient descent, no matrix inversions, no iterative optimization whatsoever.

Theorem · Naïve Bayes MLE via Joint Likelihood

The MLE estimates above maximize the joint log-likelihood: $$\ell(\phi_y, \{\phi_{j|0}\}, \{\phi_{j|1}\}) = \sum_{i=1}^{m} \left[ \log p(y^{(i)};\,\phi_y) + \sum_{j=1}^{n} \log p(x_j^{(i)} \mid y^{(i)};\, \phi_{j|y^{(i)}}) \right].$$ Because the joint log-likelihood decomposes additively across parameters, each parameter can be optimized independently, yielding the counting estimators above.

Proof

The class prior term contributes $\sum_i [y^{(i)}\log\phi_y + (1-y^{(i)})\log(1-\phi_y)]$, maximized at $\hat\phi_y = m^{-1}\sum_i y^{(i)}$. For a fixed $j$ and $k \in \{0,1\}$, the word probability term contributes $\sum_{i: y^{(i)}=k} [x_j^{(i)}\log\phi_{j|k} + (1-x_j^{(i)})\log(1-\phi_{j|k})]$, which is a Bernoulli log-likelihood in $\phi_{j|k}$ maximized at the empirical frequency of $x_j=1$ among class-$k$ examples. □

5.3.4 Prediction with Bayes' Rule

Given a new email with feature vector $\boldsymbol{x}^* = (x_1^*, \ldots, x_n^*)$, we compute the posterior class probability using Bayes' rule combined with the Naïve Bayes factorization:

$$p(y=1 \mid \boldsymbol{x}^*) = \frac{p(y=1)\prod_{j=1}^{n} p(x_j^* \mid y=1)}{p(y=1)\prod_{j} p(x_j^* \mid y=1) + p(y=0)\prod_{j} p(x_j^* \mid y=0)}.$$

In practice we compute the log of each numerator term to avoid numerical underflow from multiplying many small probabilities. The predicted label is $\hat{y} = \operatorname*{arg\,max}_{y \in \{0,1\}} p(y)\prod_j p(x_j^* \mid y)$.

Example · Classifying a New Email

Setup. Suppose $n=5$ words and a new email contains words "buy" ($j=1$) and "discount" ($j=2$) but not "meeting" ($j=3$), "the" ($j=4$), or "report" ($j=5$). Estimated parameters: $\hat\phi_y = 0.4$; for spam: $\hat\phi_{1|1}=0.8$, $\hat\phi_{2|1}=0.7$, $\hat\phi_{3|1}=0.05$, $\hat\phi_{4|1}=0.9$, $\hat\phi_{5|1}=0.03$; for non-spam: $\hat\phi_{1|0}=0.1$, $\hat\phi_{2|0}=0.08$, $\hat\phi_{3|0}=0.6$, $\hat\phi_{4|0}=0.95$, $\hat\phi_{5|0}=0.5$.

Computation (in log-space).) $\log[\hat\phi_y \prod_j p(x_j^*\mid y=1)] = \log 0.4 + \log 0.8 + \log 0.7 + \log(1-0.05) + \log 0.9 + \log(1-0.03) \approx -0.916 - 0.223 - 0.357 - 0.051 - 0.105 - 0.030 = -1.682.$ For non-spam: $\log 0.6 + \log 0.1 + \log 0.08 + \log 0.4 + \log 0.95 + \log 0.5 \approx -0.511 - 2.303 - 2.526 - 0.916 - 0.051 - 0.693 = -7.000.$

Result. Since $-1.682 > -7.000$, the model predicts $\hat{y} = 1$ (spam). The email is classified as spam because "buy" and "discount" are strong spam indicators that overwhelm the evidence from other words.

5.4 Laplace Smoothing

The Naïve Bayes algorithm as described above has a critical failure mode. Suppose a word appears in neither the spam nor the non-spam training emails — perhaps it is a technical term like "NIPS" (a machine learning conference) that simply hasn't appeared in your email corpus yet. Then the maximum likelihood estimates are $\hat\phi_{j|y=1} = 0$ and $\hat\phi_{j|y=0} = 0$. When a test email contains this word, the classifier must compute a ratio of $0/0$, causing a divide-by-zero error and making classification impossible.

More broadly, even if the word appears in one class but not the other, a single zero probability drives the entire product of conditional probabilities to zero, eliminating all evidence from the remaining words. This is statistically unjustifiable: the absence of a word from a training set does not imply the word will never occur; it merely reflects limited data.

5.4.1 The Zero-Frequency Problem

Definition · Zero-Frequency Problem

The zero-frequency problem occurs when a possible feature value or combination has zero observed frequency in the training set. For Naïve Bayes with binary features, this happens when word $j$ does not appear in any class-$k$ training example, giving $\hat\phi_{j|k} = 0$. Any test example containing word $j$ then evaluates $\prod_j p(x_j \mid y=k) = 0$ regardless of all other words, collapsing the classifier to $0/0$.

To motivate the fix, consider an analogy. Suppose you have been tracking the Stanford football team's away games for a season and they have lost all four games played so far. The MLE of their win probability is $\hat p = 0/4 = 0$ — absolute certainty of losing. But this is statistically unreasonable: you have seen only four games, and claiming zero probability of winning is far too strong a conclusion. A more careful Bayesian argument, originally due to Laplace, suggests adding a fictitious observation of each outcome.

5.4.2 Laplace's Estimator

Definition · Laplace Smoothing

For a $k$-valued discrete random variable $X$ with $n_j$ observations of value $j$ out of $N$ total observations, the Laplace-smoothed (add-one smoothed) estimate of $p(X = j)$ is: $$\hat{p}_j = \frac{n_j + 1}{N + k}.$$ More generally, with smoothing parameter $\alpha > 0$, the estimate is $\hat p_j = (n_j + \alpha)/(N + k\alpha)$. The addition of $\alpha$ to each count ensures that no probability is exactly zero, while the addition of $k\alpha$ to the denominator ensures that probabilities still sum to one.

Theorem · Bayesian Justification of Laplace Smoothing

Laplace smoothing ($\alpha = 1$) is equivalent to maximum a posteriori (MAP) estimation of a Bernoulli parameter with a uniform (Beta(1,1)) prior. Under a uniform prior $p(\phi) \propto 1$ on $\phi \in [0,1]$, the posterior mean after observing $n_1$ successes and $n_0$ failures is: $$\mathbb{E}[\phi \mid n_1, n_0] = \frac{n_1 + 1}{n_1 + n_0 + 2}.$$ This is precisely the Laplace-smoothed estimate for a binary variable ($k=2$). □

The shaded region shows the range over which smoothing meaningfully prevents zero estimates.

5.4.3 Smoothed Naïve Bayes Estimates

Applying Laplace smoothing to the Naïve Bayes binary feature model gives modified parameter estimates. Since each $x_j$ is binary (two possible values, $k=2$):

Smoothed Estimates
$$\hat{\phi}_{j|y=1} = \frac{\sum_{i=1}^{m}\mathbf{1}\{x_j^{(i)}=1,\, y^{(i)}=1\} + 1}{\sum_{i=1}^{m}\mathbf{1}\{y^{(i)}=1\} + 2}, \qquad \hat{\phi}_{j|y=0} = \frac{\sum_{i=1}^{m}\mathbf{1}\{x_j^{(i)}=1,\, y^{(i)}=0\} + 1}{\sum_{i=1}^{m}\mathbf{1}\{y^{(i)}=0\} + 2}$$

With smoothing, both estimates are bounded away from 0 and 1: $\hat\phi_{j|k} \in (0, 1)$ for all $j, k$. The zero-frequency problem is eliminated. For the class prior, the smoothing is usually not applied (or is negligible if $m$ is large), since in practice both spam and non-spam examples appear in any reasonable training set.

Example · Smoothing the "NIPS" Word

Setup. Suppose the training set has $m_1 = 200$ spam emails and $m_0 = 800$ non-spam emails. The word "NIPS" (word index $j=6017$) appears in none of the training emails. The raw MLE gives $\hat\phi_{6017|1} = 0/200 = 0$ and $\hat\phi_{6017|0} = 0/800 = 0$.

With Laplace smoothing: $\hat\phi_{6017|1} = (0+1)/(200+2) = 1/202 \approx 0.00495$ and $\hat\phi_{6017|0} = (0+1)/(800+2) = 1/802 \approx 0.00125$.

Interpretation. Now when an email containing "NIPS" arrives, the classifier assigns a slightly higher probability of being spam (0.00495 vs 0.00125). This small difference reflects the prior expectation that any word, if it were to appear, would be more likely in spam (given the higher base rate) — a mild and reasonable default. More importantly, the zero-probability catastrophe is avoided entirely.

Data Science Application · Smoothing in Production NLP Systems

Laplace smoothing is the simplest member of a broader family of regularized language models. In modern NLP pipelines, more sophisticated methods such as Kneser-Ney smoothing and Good-Turing discounting are used to redistribute probability mass to unseen events based on contextual frequency statistics. Large language models (LLMs) sidestep this problem by operating in continuous embedding spaces where the zero-probability issue does not arise directly, but smoothing intuitions resurface in regularization (weight decay), temperature scaling of softmax outputs, and label smoothing during training.

5.5 The Multinomial Event Model

The bag-of-words binary representation discards potentially useful information: if the word "drugs" appears five times in an email, the binary feature vector records only $x_j = 1$, treating it the same as an email where "drugs" appears once. For spam classification, the repetition of a word like "buy" or "discount" is itself a strong signal. This motivates an alternative representation.

Text data has a distinctive structure: emails (or documents) vary widely in length, from a five-word SMS to a thousand-word newsletter. The binary bag-of-words collapses all of them into the same $n$-dimensional space, ignoring length. The Multinomial Event Model instead represents each email as a sequence of word indices, preserving how many times each word occurs and keeping the representation proportional to email length.

5.5.1 Multivariate Bernoulli vs. Multinomial Event Model

Definition · Multinomial Event Model Representation

Let the vocabulary have size $|V| = n$. For an email of length $\ell$ (the number of word tokens), define the feature vector $\boldsymbol{x} = (x_1, \ldots, x_\ell)$ where $x_j \in \{1, 2, \ldots, n\}$ is the dictionary index of the $j$-th word in the email. The length $\ell$ varies per email. Under the Naïve Bayes assumption: $$p(\boldsymbol{x} \mid y) = \prod_{j=1}^{\ell} p(x_j = k \mid y) \equiv \prod_{j=1}^{\ell} \phi_{k|y}$$ where $\phi_{k|y} = p(\text{word at any position is word } k \mid y)$, independent of position $j$.

Figure 5.6. Two feature representations of the email "Drugs, buy drugs now." Left: Multivariate Bernoulli (binary, length 10,000). Dictionary positions for "buy" (index 3), "drugs" (index 5), and "now" (index 7) are set to 1; all others to 0. The word "drugs" appearing twice is counted only once. Right: Multinomial Event Model (word indices, length 4). The email is represented as a 4-dimensional vector where each position contains the vocabulary index of the $j$-th word. "Drugs" appears at positions 1 and 3, correctly reflecting its frequency. Red indicates "drugs," blue "buy," green "now."

The key distinction is that in the Multivariate Bernoulli model each $x_j \in \{0,1\}$ and the product runs over all $n$ dictionary words; in the Multinomial model each $x_j \in \{1,\ldots,n\}$ and the product runs over all $\ell$ word positions. The cosmetic similarity of the two models' equations — both are products of conditional probabilities under the Naïve Bayes assumption — makes them easy to confuse. The defining differences are the range of $x_j$ and the limits of the product.

Intuition · Why the Multinomial Model Tends to Perform Better

The Multinomial Event Model captures term frequency: an email saying "buy buy buy now" signals spam more strongly than one merely mentioning "buy" once. The binary model cannot distinguish these. Empirically, the Multinomial Event Model consistently outperforms the Multivariate Bernoulli for text classification tasks. The positional independence assumption — that the probability of seeing "drugs" in position 1 equals the probability in position 100 — is strong but reasonable for the spam/ham classification task where word order matters less than word presence and frequency.

5.5.2 MLE for the Multinomial Event Model

Theorem · Multinomial Event Model MLE

Let $m_k = \sum_{i=1}^{m}\mathbf{1}\{y^{(i)}=k\}$ denote the number of training examples with class $k$. The MLE of $\phi_{k|y=c}$ (the probability of word $k$ in class-$c$ emails) is: $$\hat\phi_{k|y=c} = \frac{\sum_{i=1}^{m}\mathbf{1}\{y^{(i)}=c\}\sum_{j=1}^{\ell_i}\mathbf{1}\{x_j^{(i)}=k\}}{\sum_{i=1}^{m}\mathbf{1}\{y^{(i)}=c\}\cdot\ell_i}$$ which is the fraction of words in class-$c$ emails that equal word $k$. With Laplace smoothing (vocabulary size $|V| = n$): $$\hat\phi_{k|y=c}^{\text{smooth}} = \frac{\left(\sum_{i=1}^{m}\mathbf{1}\{y^{(i)}=c\}\sum_{j=1}^{\ell_i}\mathbf{1}\{x_j^{(i)}=k\}\right) + 1}{\sum_{i=1}^{m}\mathbf{1}\{y^{(i)}=c\}\cdot\ell_i + n}$$ where $n$ is added to the denominator because the word $k$ takes on $n$ possible values.

The MLE has a beautiful interpretation: count all words in all class-$c$ emails, then compute what fraction of those words is word $k$. For instance, if among 10,000 total words appearing in non-spam emails, the word "meeting" appears 400 times, then $\hat\phi_{\text{meeting}|y=0} = 400/10000 = 0.04$. With Laplace smoothing, we add 1 to the numerator and $|V| = 10000$ to the denominator (one pseudo-count for each possible word), giving $(400+1)/(10000+10000) = 401/20000 \approx 0.020$.

Warning · Different Denominators in the Two Models

In the Multivariate Bernoulli model, smoothing adds $k=2$ to the denominator (binary outcomes). In the Multinomial Event Model, smoothing adds $|V|$ to the denominator (one for each word in the vocabulary). Mixing up these two denominators is a common implementation bug that can silently degrade classifier performance, especially for large vocabularies where the difference between $m+2$ and $m+|V|$ is dramatic.

5.6 Generative vs. Discriminative: A Principled Comparison

Having studied both families in depth, we can now make a careful comparison. The choice between generative and discriminative algorithms is not merely a matter of implementation preference — it encodes a fundamental decision about what we are willing to assume about the data-generating process. This tension is a recurring theme in statistical machine learning and reappears when we study kernel methods, neural networks, and Bayesian deep learning.

5.6.1 Modeling Assumptions and Robustness

Theorem · Exponential Family and Logistic Posteriors

Let $y \in \{0,1\}$ be Bernoulli$(\phi)$, and suppose $p(\boldsymbol{x} \mid y=k)$ belongs to the exponential family with the same base measure and sufficient statistics but different natural parameters $\boldsymbol{\eta}_k$. Then: $$p(y=1 \mid \boldsymbol{x}) = \sigma(\boldsymbol{\theta}^\top T(\boldsymbol{x}) + c)$$ for some $\boldsymbol{\theta}$ and constant $c$ determined by $\boldsymbol{\eta}_0, \boldsymbol{\eta}_1$, and $\phi$. That is, the posterior is always logistic in the sufficient statistics $T(\boldsymbol{x})$.

The theorem is remarkably broad. Whether the class-conditional distributions are Gaussian (GDA), Poisson (count data), Bernoulli (binary features — Naïve Bayes), or Exponential (positive continuous data), the posterior is always a logistic function. This means logistic regression is a correct model for any of these data-generating processes, even though it assumes nothing about the form of $p(\boldsymbol{x} \mid y)$.

ℹ️
Implication of the theorem: GDA $\Rightarrow$ logistic posterior. But logistic regression assumes only the logistic form — it makes no claim about $p(\boldsymbol{x} \mid y)$. Therefore the set of assumptions made by logistic regression is strictly contained within (i.e., weaker than) those made by GDA.
Intuition · The Bias-Variance Perspective on Generative vs. Discriminative

A generative algorithm encodes more assumptions (higher bias) but has fewer effective degrees of freedom to fit (lower variance). If the assumptions are approximately correct, this leads to better performance on small datasets — the algorithm is told more truth about the world and needs less data to exploit it. A discriminative algorithm encodes fewer assumptions (lower bias) but requires more data to learn the decision boundary from scratch. As the training set size $m \to \infty$, a discriminative algorithm typically wins because its flexibility eventually pays off and its lower bias limits the asymptotic error. For small $m$, a well-specified generative model often wins.

In contemporary machine learning practice, several factors influence the algorithm choice. The trend toward large datasets has strongly favored discriminative methods: with millions of examples, logistic regression and neural networks learn the decision boundary directly without needing to make distributional assumptions. However, generative models remain valuable in several niches.

Data Science Application · Practical Advice for Algorithm Selection

The recommended workflow for a new applied project is: (1) implement the simplest reasonable baseline quickly — for text, Naïve Bayes; for continuous features, logistic regression or GDA; (2) examine which examples the baseline misclassifies; (3) use error analysis to identify the biggest failure mode; (4) invest engineering effort to address that specific failure. This iterative approach is far more productive than spending weeks designing an elaborate algorithm before seeing any results. The computational efficiency of Naïve Bayes (parameter estimation is pure counting) makes it ideal as a quick baseline, even if logistic regression ultimately achieves higher accuracy on the same task.

✦ Chapter Summary

This chapter introduced generative learning algorithms, which model the joint distribution $p(\boldsymbol{x}, y)$ by separately estimating the class-conditional density $p(\boldsymbol{x} \mid y)$ and the class prior $p(y)$. Predictions are made via Bayes' rule. We developed Gaussian Discriminant Analysis for continuous features and the Naïve Bayes classifier for discrete and text features. The Naïve Bayes conditional independence assumption — though unrealistic — enables tractable parameter estimation (pure counting) and produces classifiers that are often surprisingly effective. Laplace smoothing addresses the zero-frequency problem by adding pseudo-counts, and the Multinomial Event Model provides a superior text representation that captures word frequencies. The chapter culminated in a principled comparison of generative and discriminative approaches: generative models make stronger assumptions, train faster, and excel with small data; discriminative models make weaker assumptions and excel with large data.

GENERATIVE VS. DISCRIMINATIVE

Discriminative algorithms model $p(y \mid \boldsymbol{x})$ directly. Generative algorithms model $p(\boldsymbol{x} \mid y)$ and $p(y)$ separately, then use Bayes' rule: $p(y \mid \boldsymbol{x}) \propto p(\boldsymbol{x} \mid y)\,p(y)$. The key trade-off is assumption strength vs. robustness.

GAUSSIAN DISCRIMINANT ANALYSIS

GDA assumes $\boldsymbol{x} \mid y=k \sim \mathcal{N}(\boldsymbol{\mu}_k, \Sigma)$ with a shared covariance. MLE gives: $\hat\boldsymbol{\mu}_k$ = class-conditional sample mean, $\hat\Sigma$ = pooled within-class scatter. The resulting decision boundary is a linear hyperplane.

GDA → LOGISTIC FORM

When the class-conditionals are Gaussian (shared $\Sigma$), the posterior $p(y=1 \mid \boldsymbol{x}) = \sigma(\boldsymbol{\theta}^\top \boldsymbol{x} + c)$ is exactly logistic. This holds more generally for any exponential family class-conditional pair differing only in their natural parameter.

NAÏVE BAYES ASSUMPTION

Features are conditionally independent given the class: $p(\boldsymbol{x} \mid y) = \prod_{j=1}^{n} p(x_j \mid y)$. This reduces the parameter count from $2^n$ to $2n+1$ for binary features, making estimation tractable via simple counting.

MLE PARAMETER ESTIMATION

Naïve Bayes MLE requires only counting: $\hat\phi_{j|y=1}$ = fraction of spam emails containing word $j$; $\hat\phi_y$ = fraction of training emails that are spam. No gradient descent. Training is $O(mn)$ in time and $O(n)$ in space.

LAPLACE SMOOTHING

Adds pseudo-counts to prevent zero-probability estimates: $\hat\phi_{j|k} = (n_{jk}+1)/(m_k+2)$ for binary features, $(n_{jk}+1)/(m_k+|V|)$ for multinomial. Corresponds to MAP estimation with a uniform Dirichlet prior. Ensures $\hat\phi_{j|k} \in (0,1)$ always.

MULTIVARIATE BERNOULLI MODEL

Binary features $x_j \in \{0,1\}$ indicate word presence/absence. Each email is a fixed $n$-dimensional binary vector regardless of length. Simple but loses word frequency information. Also called Bernoulli Naïve Bayes.

MULTINOMIAL EVENT MODEL

Each email is a sequence of word indices $(x_1, \ldots, x_\ell)$ where $x_j \in \{1,\ldots,|V|\}$. Preserves word frequency information. MLE: $\hat\phi_{k|y} = (\text{count of word } k \text{ in class-}y\text{ emails})/(\text{total words in class-}y\text{ emails})$. Typically outperforms Bernoulli NB on text.

SMALL-DATA REGIME

When training set size $m$ is small and distributional assumptions are approximately correct, generative models often outperform discriminative ones. The model's assumptions act as additional "data" — they encode prior knowledge about the data-generating process that the algorithm can leverage.

COMPUTATIONAL EFFICIENCY

Naïve Bayes and GDA are non-iterative: parameter estimation is a single pass over the training data. This enables efficient online updates — new labeled examples can be incorporated by updating counts, without re-running any optimization. A significant practical advantage for large-scale or streaming applications.
